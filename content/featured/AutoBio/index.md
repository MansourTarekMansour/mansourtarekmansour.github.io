AutoBio is the central hub for automotive enthusiasts everywhere to connect, share, and meet. Built with Flutter, Cubit state management, and Clean Architecture, AutoBio allows users to create virtual garages, showcase vehicle collections, form or join car clubs, discover events, sell vehicles directly to a like-minded community, and chat in real time using WebSockets.
